Study method

Each observation is one engine's answer to an exact prompt in one collection pass. We chose unprompted discovery, shopper constraints and branded comparisons to test substitution and when an engine supports paying more. Questions receive equal weight, which does not represent how often shoppers have each need.

The initial comparison set is Daisy, Breakstone's, Knudsen and Lactaid. We also retain every additional brand named in the answers, including private labels. This deliberately chosen outside-in sample is not a complete definition of the market.

The first brand named may not be the overall purchase choice. Lists and conditional answers do not provide comparable ordinal rankings, so we report overall lead, first textual mention and any recommendation separately. Explicit equal ties split first-choice credit. Conditional-only, unclear and no-recommendation answers stay in the denominator.

Main and supplemental answers remain separate. Baseline includes answers with visible personal or location context. Sensitivity checks retain question/pass combinations without recorded context flags across every planned engine. An unflagged answer is not proven neutral. The truncated supplemental answer is excluded with a recorded reason. Its original is retained privately; the public baseline contains an audit placeholder. The same assistant reviewed the coding, so the study has no independent human agreement check.

Trace each view through denominator IDs, membership and contribution tables, then to the reviewed answer ID. Numeric views and memberships are unchanged from the reviewed source release. Names/location phrases are withheld; originals are retained privately.
