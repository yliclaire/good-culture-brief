Code & reusable workflows

The brief is the result of a reusable research workflow. The full implementation and both workflows are in this public repository. Original interface captures and screenshots remain in a separate private archive.

Open the implementation repository ↗

Inspecting or downloading the code needs no account. Running Actions requires write access, or a fork in your own account with Actions enabled. Reading this website needs no account.

Two workflows, with review between them

  1. Collect engine answers. Choose the category, brand, competitors and questions. Preview for free; live API requests require your own keys, model settings and paid-call confirmation.
  2. Review and register. Check answers, approve coding, record exclusions and write the investment interpretation. A new study does not inherit this brief’s conclusion.
  3. Build investment brief. Recalculate reviewed evidence and generate the interactive report, print companion, evidence, tables and source kit. Rebuilding Good Culture requires no new collection or API keys.

Next quarter or a different brand

Keep the study protocol fixed for a comparable quarter. Review any model or collection changes before interpreting a trend. For another category, change the prompts, competitors, attributes and reviewed interpretation. Collection, validation, calculations and rendering carry over.
